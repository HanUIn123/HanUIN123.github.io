주요 구현 기능

1. Navigation 시스템

  • 픽셀 피킹 기반 셀 생성 및 월드 좌표 변환
  • 정점 시계방향 교정, 인접 관계/경계선 판정
  • Navigation Cell 내부 이동 제한, 층간 이동(y값 보정)

2. Geometry Shader 연출

  • Idle 상태 포자 꿈틀거림 (사인파 진동)
  • 피격 시 파편화 (난수 + 로드리게스 회전)
  • 돌 파편 원형 퍼짐 + 중력 낙하

3. Item 시스템

  • 아이템 등록/드롭/획득/복원 관리
  • 베지어 곡선 기반 아이템 드롭 궤적
  • UV 흔들림 + 팽창/수축 애니메이션

4. 상호작용 시스템

  • 림라이트 셰이더로 상호작용 오브젝트 강조
  • Lock-On 시스템 (UV 흐름, 연결 라인)
  • 상호작용 UI 버튼 (HUD 위치 변환)

5. 메쉬 인스턴싱 + 컬링 최적화

  • 인스턴싱 전용 오브젝트 클래스 설계
  • DrawIndexedInstanced() 기반 GPU 렌더링 최적화
  • CPU 프러스텀 컬링 (AABB vs 카메라 절두체 검사)

최적화 사례

  • 네비게이션 메쉬를 직접 생성하여 플레이어/몬스터가 벽·지형과 불필요한 충돌 검사를 하지 않도록 최적화
  • 메쉬 인스턴싱으로 수백 개의 동일 지형 드로우콜을 줄여 GPU 렌더링 효율 향상
  • 프러스텀 컬링으로 카메라 밖 오브젝트를 제거하여 CPU/GPU 불필요한 연산 감소

Unity 멀티 슈팅 게임 (PUN2 기반 2D 프로젝트)

개발 기간: 2025.04 ~ 2025.06 | 상태: 완료

개요

  • Photon PUN2 네트워크 환경에서 동작하는 2D 멀티 슈팅 게임입니다.
  • 최대 4명이 같은 방에 접속하여 동시에 플레이 가능하며, 실시간 채팅, 보스전, 궁극기 연출이 포함된 개인 프로젝트입니다.
  • Unity / C# / Photon PUN2 기반으로 제작하였습니다.

개발 환경

  • 언어: C#
  • 도구: Unity 2025, Visual Studio 2022
  • 네트워크: Photon PUN2

시연 영상

✈️ Multi Shooting PUN2 멀티플레이 시연 영상

📄 자세히 보기 PDF / 💻 GitHub

주요 구현 기능

1. 네트워크 시스템 (Photon PUN2)

  • 방 생성 / 참가 / 퇴장 기능 구현
  • PhotonNetwork.Instantiate로 플레이어, 총알, 보스 오브젝트 네트워크 동기화
  • RPC 호출을 통해 보스 HP 및 채팅 메시지 동기화

2. 채팅 시스템

  • TMP_InputField + ScrollRect 기반의 실시간 채팅창 구현
  • photonView.RPC()를 통한 메시지 전송 / 수신
  • 입력창 포커스 시 캐릭터 조작 입력 비활성화 처리

3. 플레이어 컨트롤

  • Unity New Input System 기반 이동, 공격, 궁극기 구현
  • 총알 발사 딜레이 및 사운드 효과 적용
  • 궁극기: 게이지 충전 → 컷인 이미지 연출 → 불꽃 광역 스킬

4. 보스전 시스템

  • 스테이지 진행도 100% 시 보스 출몰 경고 UI 표시
  • 보스 HP UI 활성화 및 3종 공격 패턴 (원형/나선/샷건)
  • 피격 시 "Hit Flash Shader"로 반짝이는 효과 적용

5. UI 및 시각적 연출

  • 궁극기 컷인은 우상단 → 중앙 슬라이드 + 흔들림 연출
  • Hit Flash Shader: _WhiteAmount 기반 점멸
  • Laser Shader: 노이즈 기반 흔들림 + 발광 효과
  • 보스 출몰 경고 UI: setActive 주기 반복 점멸 처리
  • UI 바(Image Fill): 스테이지 진행도 / 체력바 실시간 업데이트

핵심 요약

  • Photon PUN2 네트워크 시스템 구현 (방 생성, 오브젝트 동기화, RPC 통신)
  • TMP 기반 실시간 채팅 시스템 제작
  • 플레이어 조작, 몬스터 AI, Boss AI 및 탄막 패턴 구현
  • 스테이지 진행도 UI 및 보스 소환 / 경고 연출 구현
  • Shader 활용: 레이저 흔들림 / 피격 점멸 / 궁극기 컷인 효과
