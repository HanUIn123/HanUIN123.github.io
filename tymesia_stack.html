THYMESIA (DirectX11 3D 팀 프로젝트)

DirectX11 기반의 3D 액션 팀 프로젝트로, 맵툴 / 네비게이션 / 셰이더 / 아이템 시스템 구현을 담당했습니다.

C++ DirectX11 HLSL 3D Team Project

프로젝트 개요

THYMESIA는 DirectX11을 기반으로 제작된 3D 액션 팀 프로젝트로, 팀 내에서 맵툴, 네비게이션 시스템, 셰이더 연출, 아이템 시스템을 직접 설계 및 구현했습니다.
효율적인 렌더링 구조와 실제 게임 개발 파이프라인을 모방한 설계를 목표로 하였습니다.

핵심 기능

네비게이션 메쉬 시스템

픽셀 피킹, 슬라이딩 벡터, 엣지 네비게이션, 데이터 파일 관리까지 포함된 커스텀 네비게이션 구조 구현.

메쉬 인스턴싱

DrawCall 최소화를 위한 인스턴싱 구조 설계 및 AABB + 절두체(Frustum) 컬링 구현.

지메쉐 연출

Geometry Shader를 활용하여 모델 복제 및 로드리게스 회전 행렬을 통한 회전 효과 연출.

상호작용 UI & Shader

플레이어 상호작용 시 UI 표시 및 림라이트(RimLight) 셰이더를 통한 하이라이팅 효과 구현.

게임 플로우

1️⃣ 씬 로드 및 캐릭터 스폰
2️⃣ NavMesh 기반 이동 및 충돌 처리
3️⃣ 아이템 상호작용 및 UI 표시
4️⃣ Shader 연출 (RimLight, Bloom, MotionBlur)
5️⃣ 보스 처치 후 엔딩 시퀀스

핵심 구현

네비게이션 메쉬 시스템

  • 픽셀 피킹 기반 경로 지정
  • 슬라이딩 벡터 계산을 통한 장애물 회피
  • 엣지 네비게이션 경계 이동 처리
  • 데이터 파일 관리 및 NavMesh 저장

메쉬 인스턴싱

  • Instance 데이터 버퍼 관리 구조 설계
  • AABB + Frustum 컬링을 통한 성능 최적화

지메쉐 연출

  • 모델 애니메이션 및 Geometry Shader 복제
  • Rodrigues 회전 행렬 기반 회전 변환

상호작용 UI & 쉐이더

  • 상호작용 시 UI 표시 시스템
  • RimLight Shader를 통한 시각적 피드백
